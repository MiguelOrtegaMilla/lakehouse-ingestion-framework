# Code of production that no code of production reaches, and why it is left so.
#
# One entry a line: a class (a.b.C), or a member of one (a.b.C#member), and then the reason.
# An entry of a class is of everything in it, and what it uses is reached through it.
# `sbt checkUnconnected` fails on what is not reached and is not here, and on an entry that is
# reached by now or that names nothing (project/Unconnected.scala).

# Where the application starts.
lakehouse.ingestion.cli.Main  The command line: the JVM starts it.

# The model of the contract, where production goes by something else.
lakehouse.ingestion.core.control.RunStatus#mayBecome  The statuses that a run may come to. Production goes by the type of its end (RunEnd), the condition of each statement and the trigger of the schema; the tests of core hold RunEnd to this.
lakehouse.ingestion.core.control.BatchStatus#mayBecome  The statuses that a batch may come to. Production goes by the condition of each statement and the trigger of the schema.

# Measures of the LogStore that the stress runs report.
lakehouse.ingestion.logstore.CommitContext#contentionAtInsert  The versions that a writer lost at the INSERT, apart from those it was merely behind on (ADR-0004 §7). The engine records `contention`, which counts both.
lakehouse.ingestion.logstore.FaultHooks#waitsAt  That the wait a run asked for was in the path of the commits it measured.
